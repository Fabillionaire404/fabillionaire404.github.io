Datenschutzerklärung

Zweck: Assistent greift ausschließlich auf das Google-Konto des Kontoinhabers zu (Google Calendar, Gmail), um dessen eigene Termine und Fristen zu organisieren.

Daten: Gelesen werden Kalendereinträge und E-Mails des Kontoinhabers. Daten werden nur auf einem privaten Server des Kontoinhabers verarbeitet, nicht verkauft, nicht für Werbung genutzt und nicht an Dritte weitergegeben, außer an den vom Kontoinhaber gewählten KI-Dienst zur Auswertung.

Google API Services User Data Policy: Die Nutzung von über Google-APIs erhaltenen Daten entspricht der Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen.

Speicherung und Löschung: Zugriffstoken liegen verschlüsselt auf dem Server. Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden; danach werden keine Daten mehr abgerufen.
